如何使用
  1. 选择随附示例，或选择能暴露 Windows 控件的 EXE。
  2. 点击“检查接入”，查看窗口与控件识别结果。
  3. 设置操作预算后开始测试，软件会被自动操作，请勿同时操作测试窗口。
  4. 点击任意记录查看前后截图、控件、输入及判定原因，点击“实时跟随”回到当前画面。
  5. 中途停止也会保存全部已有记录并生成部分报告。
操作执行成功不代表业务正确。功能清单仅针对已适配示例；未知软件显示已观察状态和操作，不显示全软件覆盖率。问题记录是待复核观察，不自动认定漏洞。
画面为真实窗口周期截图，并非视频流。控件不兼容、权限不匹配及单实例转交会明确报告。仅用于你有权测试的软件与专用数据。
